# /analyze 스킬

오늘(또는 지정된 날짜)의 리포트를 `prompts/analyze.md` 기준으로 분석하여 학습용 마크다운을 생성한다.

## 사용법

- `/analyze` — 오늘 날짜의 리포트 분석
- `/analyze 2026-03-12` — 특정 날짜의 리포트 분석

## 실행 절차

1. **날짜 결정**: 인자가 있으면 해당 날짜, 없으면 오늘 날짜(`YYYY-MM-DD` 형식)를 사용한다.
2. **리포트 읽기**: `reports/{날짜}/` 디렉토리에서 `analysis.md` 파일과 `-analysis.md`로 끝나는 파일을 제외한 모든 `.md` 파일을 읽는다.
   - 디렉토리가 없거나 분석 대상 `.md` 파일이 없으면 "해당 날짜({날짜})에 리포트가 없습니다."라고 안내하고 종료한다.
3. **분석 기준 확인**: `prompts/analyze.md` 파일을 읽고, 그 출력 구조와 선별 기준을 따른다.
4. **분석 수행**: 모든 프로젝트/주요 변경은 `작업 커버리지` 표에 포함하고, 핵심 항목 1~3개만 `상세 학습`으로 분석한다.
5. **결과 저장**: 분석 결과를 `reports/{날짜}/claude-analysis.md`로 저장한다.
6. **텔레그램 전송**: 프로젝트 루트에서 아래 명령을 실행하여 분석 결과를 텔레그램으로 전송한다.
   ```bash
   python3 lib/notifier.py reports/{날짜}/claude-analysis.md {날짜}
   ```
   - 전송 실패 메시지가 출력되면 완료로 넘기지 말고 실패 내용을 사용자에게 알려준다.
7. **완료 메시지**: 저장 경로, 분석한 리포트 목록, 텔레그램 전송 결과를 출력한다.
